# Kayan ERP — نظام كيان لإدارة موارد المؤسسات

> **اللغات والوثائق:** [English Version (README.en.md)](README.en.md) · [خارطة الطريق والتحليل الفجوي الشامل (ROADMAP.md)](ROADMAP.md) · [دليل التثبيت الذاتي لويندوز (deploy/windows/README.md)](deploy/windows/README.md)

نظام متكامل لتخطيط وإدارة موارد المؤسسات (**Enterprise Resource Planning - ERP**) ونقاط البيع السريعة (**POS**)، مصمم ومبني خصيصاً لشركة **Kayan** الرائدة في استيراد وتوزيع إكسسوارات حريمي، توك شعر، مستلزمات زينة وهدايا من مصانع الصين إلى تجار الجملة والتجزئة والمستهلكين في السوق المحلي.

تم بناء الواجهة وتجربة الاستخدام وفق أرقى المعايير العالمية المعتمدة في أنظمة الأعمال (**Odoo Web Client** و **Daftara**)، مع دعم كامل وأصيل للغة العربية واتجاه اليمين إلى اليسار (RTL)، وفصل معماري صارم (Zero Inline JS / Zero Inline CSS)، وسرعة فائقة في التنقل السحابي (SPA via Hotwire Turbo).

## 🛠️ الحزمة البرمجية والتقنيات (Tech Stack)

- **Backend:** [Laravel 12 / 13](https://laravel.com) · [PHP 8.4 / 8.5](https://php.net) (معتمد عبر Herd Lite أو البيئة المحمولة المدمجة)
- **Database:** [MySQL 8.0 / MariaDB 10.11](https://mariadb.org) — قاعدة البيانات النشطة والمعزولة: `kayan_erp`
- **Frontend Architecture:** Blade Components & Partials مع فصل معماري صارم (Zero Inline JS / Zero Inline CSS) وسرعة التنقل عبر Hotwire Turbo
- **Styling:** CSS Design Tokens (`erp.css`) + Tailwind CSS v4 + Vite v8 + خط [Cairo](https://fonts.google.com/specimen/Cairo) مع أرقام جدولية (`tabular-nums`)
- **Testing & Quality:** [Pest PHP](https://pestphp.com) (**أكثر من 200 اختبار تكاملي ووظيفي مؤتمت**) + [Laravel Pint](https://laravel.com/docs/pint)
- **Printing Engine:**
  - محرك الويب المدمج لطباعة المستندات (A4, A5, Thermal 80mm) بتهيئة CSS `@page` ديناميكية.
  - محرك Python مدمج للطباعة الحرارية المباشرة (Direct TSPL & Thermal Printing) لملصقات الباركود 38×25 مم و 38×15 مم.
- **Desktop Launcher:** تطبيق مشغل ويندوز أصلي بلغة C# (`KayanERP.exe`) لتشغيل الخدمات في الخلفية وفتح واجهة الكاشير ملء الشاشة عبر Microsoft Edge WebView.

## 🎨 تفاصيل الوحدات والوظائف المنجزة (Implemented Modules)

### 1. نظام نقطة البيع والكاشير السريع (POS & Cashier Shift Management)
- **شاشة الكاشير التفاعلية (`/pos` & `/sales/create`):**
  - دعم مسح الباركود السريع بالماسح الضوئي (Barcode Gun) أو البحث الفوري بالاسم والكود بزر `Enter`.
  - التبديل الفوري بين البيع بالقطعة والدستة (Piece vs Dozen) مع احتساب معامل التحويل آلياً.
  - تطبيق فئات التسعير الأربعة تلقائياً بحسب نوع العميل (تجزئة، جملة، موزع، جملة خاصة).
  - دعم البيع النقدي، البيع الآجل بالكامل، والدفع الجزئي مع التنبيه الفوري لتجاوز سقف الائتمان.
- **إدارة الورديات ودرج النقدية (`/cashier-shifts`):**
  - فتح الوردية وتوثيق رصيد أول المدة بالدرج.
  - تسجيل المصروفات اليومية الطارئة مباشرة من شاشة الكاشير وخصمها من الدرج.
  - تسجيل سندات القبض والدفعات النقدية المحصلة أثناء الوردية وربطها آلياً بحركة الدرج.
  - إغلاق الوردية، احتساب العجز والزيادة (Discrepancy)، وطباعة ملخص الوردية الحراري 80mm.

### 2. الشجرة المحاسبية والقيود والتقارير المالية (General Ledger & Financial Suite)
- **دليل الحسابات الهرمي التفاعلي (`/accounting/chart-of-accounts`):**
  - شجرة حسابات قياسية متعددة المستويات (الأصول، الخصوم، حقوق الملكية، الإيرادات، والمصروفات).
  - إمكانية إضافة حساب رئيسي أو فرعي، وتحديد طبيعة الحساب (مدين / دائن).
- **القيود اليومية المزدوجة التلقائية (`/accounting/journal-entries`):**
  - محرك ترحيل آلي يُنشئ قيود اليومية المتوازنة فور ترحيل فواتير المبيعات، المشتريات، المرتجعات، سندات القبض، والصرف.
  - صفحة عرض وطباعة لسند القيد اليومي مع التوقيعات الرسمية.
- **القوائم والتقارير المالية المعيارية (`/accounting/reports/*`):**
  - **ميزان المراجعة (Trial Balance):** أرصدة الحسابات ومجاميع الحركات للتأكد من توازن الدفاتر.
  - **قائمة الدخل والأرباح والخسائر (Income Statement / P&L):** تتبع الإيرادات، تكلفة البضاعة المباعة (COGS)، مجمل الربح، المصروفات التشغيلية، وصافي الربح.
  - **الميزانية العمومية (Balance Sheet):** عرض الأصول، الخصوم، وحقوق الملكية والتوازن المالي للمؤسسة.
  - **دفتر الأستاذ العام (General Ledger):** كشف حركة تفصيلي لكل حساب مع الرصيد التراكمي.

### 3. دورة حسابات العملاء المتقدمة وتسوية الفواتير (Customer Accounts & FIFO Allocation)
- **كشف الحساب التراكمي الدقيق (`/customers/{customer}/statement`):**
  - رصيد أول المدة الافتتاحي (مدين/دائن) يظهر في السطر الأول، يتبعه سحب الفواتير وسداد السندات بالترتيب الزمني.
  - إمكانية طباعة كشف الحساب بـ 3 مقاسات (A4 رسمي، A5 اقتصادي، 80mm حراري) ومشاركته بضغطة زر عبر الواتساب.
- **التسوية التلقائية للفواتير المفتوحة (FIFO Auto-Allocation):**
  - عند تسجيل دفعة سداد عامة على حساب العميل، يوزع النظام المبلغ تلقائياً على الفواتير الآجلة المعلقة من الأقدم للأحدث.
  - الفواتير المسددة تتحول فوراً إلى علامة خضراء `مسددة بالكامل` مع تصفير المتبقي عليها.
- **سجل سندات القبض والدفعات:**
  - جدول مخصص داخل ملف العميل يعرض تاريخ السند، رقم السند، طريقة الدفع (نقدي، بنكي، شيك، شبكة)، وزر طباعة إيصال الاستلام المالي.

### 4. إدارة الأصناف والتسعير الرباعي والمخزون بـ FIFO
- **هيكل تسعير رباعي متقدم:** (1) سعر التكلفة، (2) سعر الجملة، (3) سعر الموزع، (4) سعر التجزئة.
- **محرك صرف FIFO المخزني:** تتبع كل شحنة شراء بدفعتها المخزنية (`inventory_batches`) وتكلفتها لحساب تكلفة البضاعة المباعة (COGS) وهامش الربح الحقيقي بدقة.
- **استيراد إكسيل الذري (`/products/import`):** استيراد وتحديث آلاف الأصناف مع معالجة الأخطاء داخل معاملة آمنة `DB::transaction`.
- **طباعة الباركود الحرارية (38×25 مم & 38×15 مم):** دعم الطابعات المباشرة وXprinter مع دوران 90° و 270°.

### 5. منظومة المشتريات والموردين ومصانع الصين
- فواتير مشتريات متعددة البنود مرتبطة بمصانع الصين (مع حفظ WeChat ID والعملة)، مكاتب الشحن الدولي، والمستودع المستلم.
- كشف حساب المورد، تسجيل سندات الصرف، وجدولة الأقساط والمستحقات.

### 6. بوابة مندوبي المبيعات والعمل الميداني (Sales Reps Portal & GPS)
- بوابة ويب مخصصة للموبايل والتابلت تتيح للمندوب تسجيل الحضور والانصراف بإحداثيات الـ GPS الجغرافية.
- تسجيل زيارات العملاء الميدانية مع توثيق الموقع، وطلب إضافة وتسجيل عملاء جدد للاعتماد من الإدارة.
- احتساب عمولات المبيعات آلياً بنظام النسبة أو المبلغ الثابت مع ترحيل الفواتير.

### 7. حزمة التثبيت الذاتي للعملاء (Windows One-Click Installer)
- **مشغل سطح المكتب الأصلي (`KayanERP.exe`):** تطبيق تنفيذي (22KB) تم بناؤه بلغة C# يقوم بفحص وتشغيل الخوادم صامتاً في الخلفية، ويفتح البرنامج في وضع **Edge Desktop App Mode** ملء الشاشة بدون شريط متصفح وبدون شاشات سوداء.
- **سكربت Inno Setup (`deploy/windows/installer.iss`):** سكريبت جاهز لتوليد ملف التثبيت الموحد `KayanERP-Setup.exe` (100% English ASCII Paths) لنقل وتهيئة البرنامج وقاعدة البيانات بضغطة زر عند أي عميل جديد.
- **النسخ الاحتياطي التلقائي (`scripts/backup.bat`):** نسخ احتياطي يومي مجدول لقاعدة البيانات في مجلد منفصل `C:\KayanERP_Backups`.

## 🚀 دليل التشغيل والتطوير (Getting Started)

### الخيار الأسرع (للاستخدام اليومي على ويندوز):
انقر مرتين على ملف **`KayanERP.exe`** في المجلد الرئيسي للمشروع، وسيبدأ السيرفر في الخلفية ويفتح واجهة البرنامج فوراً كبرنامج سطح مكتب مستقل.

### التشغيل التقليدي للمطورين (Development Environment):

1. **تثبيت الاعتماديات:**
   ```bash
   composer install
   npm install
   ```

2. **تهيئة البيئة وقاعدة البيانات:**
   ```bash
   # ضبط ملف .env على قاعدة بيانات kayan_erp
   php artisan migrate --seed
   ```

3. **بناء أصول الواجهة:**
   ```bash
   npm run build
   # أو أثناء التطوير الحي:
   npm run dev
   ```

4. **تشغيل الخادم:**
   ```bash
   php artisan serve --port=8000
   ```
   *الرابط المحلي:* [http://127.0.0.1:8000](http://127.0.0.1:8000)

5. **تشغيل الاختبارات وفحص الجودة:**
   ```bash
   php artisan test --compact
   ```

## 🔒 قواعد الأمان وحماية البيانات (Safety Rules)

- **قاعدة البيانات النشطة والمعزولة:** النظام مرتبط حصرياً بقاعدة البيانات `kayan_erp`. يُمنع منعاً باتاً استهداف قاعدة البيانات القديمة `kayan`.
- **المعاملات الذرية (ACID Transactions):** أي قيد مالي أو سداد فاتورة أو خصم مخزني أو استيراد يتم حصرياً داخل `DB::transaction` لضمان عدم وجود أرصدة معلقة أو حركات غير متزنة.
- **الفصل المعماري الصارم للواجهات:** خالٍ تماماً من وسوم `<script>` أو سمات `style="..."` في قوالب Blade، مما يضمن أفضل أداء وأعلى درجات الأمان وسرعة فائقة مع Hotwire Turbo.
