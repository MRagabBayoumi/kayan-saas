# Kayan SaaS — المنصة السحابية المتكاملة لإدارة المؤسسات والمشتركين
## Kayan Multi-Tenant Enterprise SaaS & ERP Platform

> **اللغات والوثائق:** [English Version (README.en.md)](README.en.md) · [خارطة الطريق والتحليل الفجوي الشامل (ROADMAP.md)](ROADMAP.md)

منصة سحابية متطورة وشاملة متعددة المستأجرين (**Multi-Tenant SaaS**) مبنية فوق نظام **Kayan ERP** الرائد. توفر المنصة نظام إدارة مركزي للمشتركين والشركات مع عزل أمني وصلاحيات ديناميكية لكل مستأجر، بالإضافة إلى كافة وحدات إدارة الأعمال والمخازن ونقاط البيع السريعة (**POS**) والتجارة الإلكترونية (**E-Commerce**).

## 📌 الوحدات المشتركة والمحدثة مع Kayan ERP

تمت مزامنة كافة التحسينات والميزات الحديثة من Kayan ERP إلى المنصة السحابية:

1. **قوائم التعبئة والتجهيز (Packing List Module - `/packing-list`):**
   - واجهة تفاعلية لتجهيز شحنات العملاء، حساب الطرود، التصدير إلى Excel/CSV، والطباعة بـ 3 مقاسات (A4, A5, 80mm).
2. **تقارير مديونيات العملاء وقوائم الأسعار:**
   - تقرير شامل للأرصدة المستحقة ومقارنتها بحدود الائتمان (`/customers/balance-due-report`) مع طباعة رسمية.
   - كتالوج وقائمة أسعار للأصناف بالهيكل الرباعي (`/products/price-list`) قابلة للطباعة والتصدير.
3. **مرونة الباركود وتعدد الأكواد وإلغاء قيد تفرد SKU:**
   - دعم تسلسل باركود داخلي يبدأ من `10001` لسهولة الطباعة والمسح الحراري.
   - إمكانية تشارك نفس كود الموديل (SKU) بين أصناف متعددة لتسهيل إدارة الألوان والمقاسات والتنويعات.
4. **حماية أسعار التكلفة في نقاط البيع:**
   - عزل تكلفة الشراء عن موظفي الكاشير وربطها بصلاحية استثنائية `view-cost-price` لحماية هوامش الربح.
5. **المتجر الإلكتروني المدمج (E-Commerce Storefront - `/shop`):**
   - متجر إلكتروني متكامل لكل مستأجر مع سلة مشتريات وتتبع الطلبات والتحكم الفوري في إتاحة المنتجات أونلاين.
6. **مكدس الإنتاج عالي الكثافة (Multi-Worker Live Stack):**
   - دعم التشغيل عبر Apache كـ Reverse Proxy و 4 خوادم PHP في الخلفية بدون نوافذ منبثقة.

## 🛠️ الحزمة البرمجية (Tech Stack)

- **Backend:** [Laravel 12 / 13](https://laravel.com) · [PHP 8.4 / 8.5](https://php.net)
- **Database:** [MySQL 8.0 / MariaDB 10.11](https://mariadb.org) — قاعدة بيانات مركزية وقواعد بيانات المستأجرين
- **Frontend:** Blade Components + Tailwind CSS v4 + Vite + Hotwire Turbo SPA
- **Testing:** [Pest PHP](https://pestphp.com) مع تغطية شاملة لكافة الوحدات واختبارات الصلاحيات
- **Formatting:** [Laravel Pint](https://laravel.com/docs/pint)

## 🚀 دليل التشغيل السريع (Getting Started)

### 1. تشغيل خادم التطوير السحابي:
```bash
# تشغيل خادم المنصة المركزية
./start-saas.bat
# أو يدوياً:
php artisan serve --port=8000
```

### 2. الدخول إلى لوحة التحكم المركزية (Central SaaS Dashboard):
افتح المتصفح على:
**[http://localhost:8000/saas](http://localhost:8000/saas)**

### 3. تشغيل مكدس الإنتاج عالي الكثافة:
```powershell
.\start-live-server.ps1
```

### 4. تشغيل حزمة الاختبارات:
```bash
php artisan test --compact
```
